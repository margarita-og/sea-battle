# Морской бой

Консольная реализация классической игры "Морской бой" на C#.

## Правила игры

### Цель игры
Первым потопить все корабли противника.

### Состав флота
- 1 корабль — 4-палубный ("четырехтрубный")
- 2 корабля — 3-палубных ("трехтрубных")  
- 3 корабля — 2-палубных ("двухтрубных")
- 4 корабля — 1-палубных ("однотрубных")

### Игровой процесс
1. **Расстановка кораблей**:
   - Корабли не могут соприкасаться друг с другом (даже углами)
   - Корабли располагаются только по горизонтали или вертикали
   - Все корабли должны находиться в пределах поля 10×10

2. **Ходы игроков**:
   - Игроки ходят по очереди
   - При попадании игрок получает право на дополнительный выстрел
   - При промахе ход переходит к противнику

3. **Потопление корабля**:
   - Корабль считается потопленным, когда все его палубы подбиты
   - При потоплении программа покажет, что корабль уничтожен

### Обозначения на поле
   - Вода на поле обозначается так - '~'
   - При заполнении игроком своего поля корабль отображается так '■'
   - Промах обозначается так 'O'
   - Попадание обозначается так 'X'
   - Уничтоженный корабль обозначается так '#'

## Запуск игры

### Требования
- .NET 6.0 или выше
- Консоль, поддерживающая Unicode

### Сборка и запуск

```bash

# Сборка проекта
dotnet build

# Запуск игры
dotnet run

## Особенности реализации

- **Валидация ввода**: Проверка формата координат (A1-J10)
- **Проверка расстановки**: Контроль правильности размещения кораблей
- **Определение потопления**: Автоматическое обнаружение полностью уничтоженных кораблей
- **Обработка границ**: Корректная работа с краями игрового поля

## Как играть

### Фаза расстановки
1. **Ввод координат кораблей** через пробел (например: `"A1 B1 C1"`)
2. **Программа проверяет корректность расстановки** - правильность формата, отсутствие пересечений и касаний кораблей
3. **Передайте устройство следующему игроку** для расстановки его флота

### Фаза боя
1. **Вводите координату выстрела** (например: `"E5"`)
2. **Наблюдайте результат на обновленном поле** - попадания (`X`), промахи (`O`) и потопленные корабли (`#`)
3. **При попадании - ходите повторно** до первого промаха

## 🛠 Архитектура проекта

### Основные методы
- **`PrintBothFields()`** - отображение двух игровых полей одновременно с координатной сеткой
- **`ProcessingPlayersMove()`** - обработка хода игрока, включая валидацию ввода и обновление поля
- **`ShipDestroyed()`** - проверка полного уничтожения корабля и пометка соседних клеток
- **`FieldSetup()`** - интерактивная фаза расстановки кораблей с пошаговыми инструкциями

### Структура данных
- **Двумерные массивы `char[10,10]`** для хранения состояния игровых полей
- **Кортежи `(int x, int y)`** для работы с координатами клеток
- **Списки `List<(int x, int y)>`** для хранения координат кораблей и групп клеток
